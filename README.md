# 🎓 Ciência da Computação — UFMG

Repositório central (**umbrella repository**) que consolida as disciplinas, projetos práticos, trabalhos, listas e códigos desenvolvidos ao longo da graduação em **Ciência da Computação** na **Universidade Federal de Minas Gerais (UFMG)**.

---

## 📌 Estrutura do Repositório

Os projetos com repositório próprio no GitHub estão integrados neste repositório geral através de **Git Submodules**, mantendo o histórico, as branches e os commits de cada projeto de forma totalmente independente e desacoplada.

```text
ufmg/
├── 6_semestre/       # Compiladores, Redes, SO, Engenharia de Software
├── 7_semestre/       # IIA, AMB, CML, FSPD, PLN, SPA
├── 8_semestre/       # Teste de Software, HEM, SMT, IAM, ICV, Libras
└── Arquivos/         # Materiais gerais do curso e notas
```

## 🛠️ Guia de Uso do Repositório (Git Submodules)

### 1. Clonar este repositório completo com todos os submódulos
```bash
git clone --recurse-submodules <URL-DO-REPOSITORIO-UFMG>
```

Se já clonou sem `--recurse-submodules`:
```bash
git submodule update --init --recursive
```

### 2. Trabalhando em um projeto específico
Cada submódulo é um repositório Git completo. Você pode entrar na pasta correspondente e commitar normalmente:
```bash
cd 8_semestre/"Teste de Software"
git add .
git commit -m "feat: novos testes com pytest-mock"
git push
```

### 3. Atualizando as referências no repositório geral
Após atualizar qualquer submódulo (ou fazer alterações em arquivos gerais), atualize o ponteiro no repositório raiz:
```bash
cd /home/mateuszaparoli/ufmg
git add .
git commit -m "chore: atualiza submódulos e notas"
git push
```

### 4. Baixar atualizações de todos os submódulos de uma vez
```bash
git submodule update --remote --merge
```
